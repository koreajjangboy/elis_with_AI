# elis_with_AI

전국 자치단체 자치법규(조례·규칙)를 기반으로 한 검색 강화형 RAG 시스템.

## 목표
- 자치법규를 조문 단위(조·항·호)로 구조화하여 수집·색인
- 하이브리드 검색(BM25 + 임베딩), 메타데이터 필터(자치단체·시행일), 리랭킹
- 답변 시 근거 조문 인용 (예: OO시 OO조례 제5조 제2항)

## 진행 단계
- [x] 0. 저장소 및 기본 골격
- [ ] 1. 범위·사용 시나리오 정의
- [ ] 2. 데이터 확보 (국가법령정보센터 Open API 검증)
- [ ] 3. 데이터 모델·청킹 설계
- [ ] 4. 검색 파이프라인 구현
- [ ] 5. 평가셋 구축 및 성능 측정

## 디렉터리 구조
```
data/       # 원본/가공 데이터 (git 제외)
docs/       # 설계 문서

```
